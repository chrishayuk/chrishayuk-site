# Fonts for generated social artwork

Social editions use the same families as the publication: Newsreader for display and Archivo for text. The ImageResponse renderer receives local static TTF instances, generated with fontTools from the Google Fonts variable sources:

- Newsreader-Regular.ttf: weight 400, optical size 72. Source: https://github.com/google/fonts/blob/main/ofl/newsreader/Newsreader%5Bopsz,wght%5D.ttf
- Archivo-Regular.ttf: weight 400, width 100. Source: https://github.com/google/fonts/blob/main/ofl/archivo/Archivo%5Bwdth,wght%5D.ttf

Downloaded 25 September 2026. The adjacent OFL-Newsreader.txt and OFL-Archivo.txt licenses apply.

Previously used assets retained for compatibility: Fraunces.ttf is a static instance (weight 400, optical size 72, SOFT 0, WONK 1) of Google Fonts Fraunces, generated with fontTools. Geist-Regular.ttf is the OFL font bundled with next/og. Their adjacent licenses apply.
