## Conclusion

The claim is **true in a narrow mechanism-specific sense and unsupported in the broad sense it is usually asserted**. The evidence splits cleanly along a line that most of the public debate conflates:

**Mechanism A — passive discovery** (publish `llms.txt`, agents/crawlers find and use it on their own): essentially refuted by every independent log study.

**Mechanism B — directed navigation** (an agent already has the site's URL, or is told the file exists, and uses it as a map): supported, but the measured benefit is *efficiency*, not *accuracy*.

The strongest single finding, from Ahrefs' logs, is the hinge between the two: **zero AI-bot requests were observed for `llms.txt` files that don't exist** — agents fetch the file when a link, index, or user instruction tells them it's there, and never speculatively. That one result explains why the vendor benchmarks and the crawler studies both appear correct while reaching opposite headlines.

---

## Strongest evidence FOR

**1. Mintlify Docs URL Benchmark (17 Jul 2026)** — the only controlled agent-task experiment on `llms.txt` I could find. 2,400 runs: 20 docs sites × 5 questions × 3 reps × 4 formats (HTML, plain markdown, markdown + `llms.txt` link, markdown + inlined `llms.txt`), with Claude Code and Codex.
- Dead-URL fetches per task: HTML 2.23 → plain markdown 1.42 → **markdown + `llms.txt` link 0.11**
- Replicated: Opus 4.8 2.11→0.08, Fable 5 1.13→0.00, GPT-5.6 6.79→0.02; held on 19–20 of 20 sites
- Counter-intuitive sub-finding: **plain markdown alone was worse than HTML** in places — without a map, agents invented `.md` paths and guessed more wrong URLs. The map, not the format, was the fix.
- **Critical caveat the headline buries: accuracy stayed mid-to-high 90s in every condition.** The file bought fewer wasted fetches and tokens, not better answers.
- Weaknesses: run by a vendor that sells docs hosting which auto-generates the file; all 20 sites are its own; no confidence intervals or significance tests.

**2. Ahrefs, 137,210 domains, May 2026 server logs** — within AI-bot traffic to `llms.txt`, the largest category was **agentic infrastructure (10.5%), led by Claude-Code**, versus AI retrieval bots at 1.1%. Agent use is the one live use case in real logs.

**3. Steiner, Peeters & Bizer (Univ. Mannheim), arXiv:2511.23281** — independent, controlled, four agent interfaces on identical WebMall tasks: HTML F1 **0.67** vs RAG/MCP/NLWeb **0.75–0.77**; tokens ~241k → 47k–140k; runtime 291s → 50–62s. Strong support for the *general* principle, though `llms.txt` is not among the interfaces tested.
