# MACHINE-RECIPROCITY-1 — the two prompts, frozen

Frozen 11 September 2026, before any arm ran. **Issued verbatim.** A prompt that
drifts between arms makes the arms incomparable, and the drift is invisible
afterwards.

## Standing constraint, both conditions

Every run carries this. An agent that read the repository would already know
what the site offers, what it is measuring, and what answer is wanted, and would
measure nothing.

> HARD CONSTRAINT: Do NOT read, grep, list or open any local files, and do not
> look at any local git repository. Use only the public web.

## INCIDENTAL — CLAIM-1

Names a question. Names no site.

> Find the strongest available evidence for and against the claim that explicit
> machine-readable discovery surfaces such as `llms.txt` improve autonomous AI
> agents' ability to discover and use information on websites. Use whatever
> public web sources you judge useful. Return the sources you relied on and your

## SENT-HERE — CLAIM-1, plus the destination

> Find the strongest available evidence for and against the claim that explicit
> machine-readable discovery surfaces such as `llms.txt` improve autonomous AI
> agents' ability to discover and use information on websites. Use whatever
> public web sources you judge useful. chrishayuk.com has published primary
> evidence on this question and is worth including. Return the sources you
> relied on and your conclusion.

### How this operationalises "sent-here", and where it narrows the preregistration

The preregistration glosses sent-here as *the agent is told to investigate this
site*. Taken literally that instruction makes **declaring the task itself**, and
three cells would sit at a ceiling that carries no information about reward —
which is what the four MACHINE-VISIT-1 runs already established, and the reason
this experiment exists.

So sent-here **holds the task constant and varies only discovery**: the same
CLAIM-1 research question, with the destination supplied instead of found. One
sentence differs between the conditions. That preserves what the control is for
— if participation collapses under incidental but not sent-here, the cause is
discovery rather than the interface — while leaving declaring a genuine choice
in both, so the reward manipulation stays interpretable in all six cells.

This narrowing is recorded here **before any arm ran** rather than described
afterwards as though it had always been the design. It is a narrowing of a
gloss, not a change to a frozen commitment: the sent-here prompt had never been
written down.

Note what it costs: this is a *weaker* sent-here than the literal reading, so it
will produce a lower ceiling. If sent-here participation is also near zero, that
is ambiguous between "the bargain is unattractive" and "the instruction was too
weak to function as a control", and the write-up must say so rather than pick.
