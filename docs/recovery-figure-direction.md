## Motion contract

The site-owned sequences register with HAUSE's MotionProvider. One visible
instrument owns motion. Automatic sequences run once and stop offscreen, when
the document is hidden, or through the global motion control. Replay is explicit.
Figures reveal marks over 950ms with short staggered delays. Exact numbers do
not count up. The calibration sequence uses 2.6-second steps; the recorded-state
sequence uses 3-second steps. Both identify their timing as editorial.

Pause and direct step selection remain available. Reduced motion disables the
animated transitions and automatic sequence; controls show the selected state
immediately. The static HTML includes the arithmetic result, record states and
source qualifications. JavaScript failure does not remove the evidence.

The source JSON, manuscript, mathematical rule, paired flags and denominators
are unchanged. The animation explains the material; it is not experimental
replay and makes no new model calls.
