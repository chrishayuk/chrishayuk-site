# HAUSE sharing contribution

The publication consumes HAUSE `Share`, `shareLinks` and `share.css` from commit `b785b0508b251b5a57eaf163b19c44164cd0feec`. The files are mirrored into the existing vendor alongside the earlier publication and evidence contributions; the original base revision remains documented separately.

HAUSE owns LinkedIn/X share destinations, canonical URL encoding, the Copy disclosure and clipboard feedback. It includes no SDK or posting API. Chris's site supplies the idea, URL and eligibility rules, and owns the deterministic social card, recorded status and editorial distribution drafts. The hause.design publication specimen documents and demonstrates the same component.
