# Editorial threads

`/thread/the-map` is a curated reading route through the original map film, N-MAP, N-STATE, N-ADDRESS, the constructed memory study, LARQL and VINDEX3. Its order teaches the question; it does not assert a chronology or causal history. Member titles, destinations, publication dates and draft statuses resolve from existing records. No new finding or historical experiment date is inferred.

`lib/threads.ts` is the source for the page, onward navigation, graph membership and sitemap entry. The homepage and notebook collection offer the route; participating record, film and demo pages show previous/next destinations and a link back to the current step. Unrelated records do not acquire a thread link. The existing primary navigation and homepage sequence remain intact.

The page uses HAUSE metadata and JSON-LD with an ordered ItemList. Each visual/text pairing is an editorial Connection; original film frames, existing explanatory studies and a computed demo preview remain clearly differentiated. It adds no autoplay source.

The graph exposes the guide as `curated-thread` with ordered members and reciprocal membership edges labelled `editorial-reading-order`. Its source text is the text shown on the guide. This working edition is excluded when Ask excludes editorial drafts. A separate `constructed-example` node identifies the browser study. Reading order is not represented as a causal, chronological, evidential or supersession edge.

Thread membership does not publish a notebook, alter its version, enter it in a publication feed, ingest an external repository, or convert metadata into a transcript. Source citations remain on the individual records. New guides should be curated from resolved records and tested for working destinations, honest source status and meaningful onward choices.
